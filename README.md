# AI-Powered Employee Goal Intelligence Platform

Enhanced web application MVP with premium dashboard UX and core BRD workflows.

## Delivered
- Goal creation + AI goal suggestion pack
- Validation rules (max 8 goals, min 10% per goal, 100% total)
- Manager approval/rework workflow with locking
- Quarterly tracking (status + achievements) and formula-based progress
- AI risk alerts for managers and predictive risk counts for admin
- Admin governance (unlock, audit trail, CSV report export)
- Completion and risk analytics cards

## Run
Open `index.html` in a browser.
