# ATOM QUEST - Goal Setting & Tracking Portal

A browser-based MVP covering the BRD core workflow:
- Employee goal creation with validation rules (max 8 goals, min 10% each, total 100%)
- Manager approval/return flow with lock behavior
- Quarterly progress status and achievement updates with formula-based progress
- Admin unlock, audit trail, and CSV export

## Run
Open `index.html` in any browser.

## Demo roles
- Employee
- Manager (L1)
- Admin/HR

Role switching is available directly in the UI for demo convenience.
